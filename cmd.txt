# MqttSubscriberService giờ giải mã khung nhị phân theo "GIAO THỨC TRUYỀN TIN NODE-GATEWAY"
# (Start 0x53 | Command 0xA7 | Length | NodeId | Payload TLV | CRC16 | Stop 0x4D), không còn
# nhận JSON qua mosquitto_pub -m nữa. Dùng publisher C# mới để build đúng khung này:
#
#   dotnet run --project NodePublisherSim
#
# Biến môi trường tùy chỉnh (đều có default hợp lý nếu bỏ qua):
#   MQTT_BROKER_HOST=localhost
#   MQTT_BROKER_PORT=1883
#   NODE_ID=1                      # 1~254, ghi vào byte Node ID của khung
#   PUBLISH_INTERVAL_SECONDS=1
#
# Mỗi lần publish gửi 1 khung chứa cả 4 loại cảm biến (ánh sáng, mực nước, nhiệt độ/độ ẩm,
# radar) lên topic sensors/{NODE_ID}/reading. Xem WireProtocol/ cho codec dùng chung giữa
# publisher và BackendV2.
