1. Actor: Station đọc sensor realtime + frame camera; Node (Raspberry Pi) 
gắn sensor + camera, đẩy dữ liệu lên Backend. (Bỏ qua user/login.)

2. Data: Node là entity cấp cao nhất (không có Station trong DB) 
→ Node 1-N Sensor, Node 1-N Camera. 
Sensor là định nghĩa thiết bị (kèm ngưỡng cảnh báo, dùng sau). 
Reading là giá trị đo theo thời gian, thuộc timeseries DB, tách khỏi Sensor.

3. Realtime: Reading + camera frame → realtime. 
Danh sách Node/Sensor/Camera → load 1 lần lúc mở app.

4. Background: ghi Reading xuống timeseries DB, health check Node, 
nhận data từ Node — chạy nền độc lập UI.

5. Ngoài phạm vi (hoãn lại): Alert khi vượt ngưỡng, 
Auth/phân quyền — ghi rõ để không quên, làm sau khi pipeline core ổn.
