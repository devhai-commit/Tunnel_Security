Kiến trúc tổng thể
Thành phần bên ngoài:

Node (Raspberry Pi, không thuộc code Backend) — publish sensor reading qua MQTT, gửi camera frame qua WebSocket
MQTT Broker (VD: Mosquitto) — hạ tầng riêng, cả Node và Backend đều là client kết nối vào, không phải một phần của ASP.NET Core app — cần cài/chạy độc lập.
Backend (ASP.NET Core):

Layer	            Thành phần
Ingestion	        MqttIngestionService (background service, subscribe broker) · WebSocket endpoint nhận camera frame từ Node
Domain/Processing	Reading nhận vào → ghi TimescaleDB + broadcast SignalR. Camera frame nhận vào → relay ngay cho Station đang kết nối
Persistence	        SQL Server (Node, Sensor, Camera — topology, EF Core) · TimescaleDB (Reading — time-series)
Output realtime	    SignalR hub (/hubs/sensors) đẩy Reading · WebSocket endpoint riêng đẩy Camera frame cho Station
REST API	        Trả topology (Node/Sensor/Camera) — Station gọi 1 lần lúc khởi động
Background	        Health check Node (dựa last-seen)
Hoãn lại	        Alert theo ngưỡng, Auth/phân quyền

2 luồng dữ liệu chính:


Flow A (Sensor):
Node --MQTT publish--> Broker --subscribe--> Backend(MqttIngestionService)
     --> ghi TimescaleDB
     --> broadcast qua SignalR --> Station

Flow B (Camera):
Node --WebSocket--> Backend(WS endpoint nhận frame)
     --> relay ngay --> Backend(WS endpoint phát cho Station) --> Station
Station khi mở app: gọi REST lấy topology 1 lần → connect SignalR (nhận Reading) → connect WebSocket riêng (nhận Camera frame).
